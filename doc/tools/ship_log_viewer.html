未连接串口
Web Serial 需要在 `http://127.0.0.1` 或 `http://localhost` 下打开。
“已配对”不代表“遥控在线”，遥控在线只以最近收到 `0x11` 和超时日志为准。
当前页支持在线串口解析，也支持离线粘贴 `.log/.txt` 日志。
