# 自稳定逻辑说明

## 当前主链路

当前工程中的主链路为：

```text
遥控输入 / AutoDrive 目标
-> MainLoop 提供当前运行状态与统一导航航向
-> ShipControl 计算最终左右电机目标
-> Motor 执行 PWM 输出
```

对应源码关系：

- `User/MainLoop.c`
- `Code_boweny/Device/Control/ShipControl.c`
- `Code_boweny/Device/Motor/Motor.c`

## 姿态与航向来源

- `AHRS` 负责输出原始融合姿态和原始融合航向基准。
- `HeadingEstimator` 负责轻量级航向融合。
- `NorthCalib` 负责把原始融合航向进一步转换为统一导航北向参考。
- `MainLoop_GetHeadingDeg100()` 是当前控制层应使用的统一导航航向出口。

## 当前职责边界

- `AutoDrive` 负责目标点、返航条件和目标航向规划，不直接输出最终电机命令。
- `ShipControl` 是当前工程中唯一应负责最终左右电机目标决策的上层模块。
- `Motor` 只负责执行左右电机目标，不负责模式切换、航向规划或姿态融合。

## 当前注意事项

- 若旧文档提到“AutoDrive 直接控制电机”或“传感器模块直接闭环电机”，应视为历史路径，不代表当前实现。
- 若旧文档把 AHRS 输出直接当作最终导航航向，应以 `MainLoop_GetHeadingDeg100()` 的统一出口为准。
