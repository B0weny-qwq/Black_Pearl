# 产品后续改进点：启动流程与磁力计校准

记录日期：2026-05-31

## 1. 背景

本次讨论围绕黑珍珠项目的启动流程、遥控器优先级、磁力计校准和自稳/巡航启用条件展开。

当前目标不是立即把自稳逻辑直接插入，而是先规划一个可扩展的磁力计校准模块，让用户可以在岸上通过遥控器触发校准，并将校准参数保存到 EEPROM。

## 2. 启动流程改进

后续启动流程应调整为：

1. 优先初始化射频和射频前端。
2. 优先执行遥控器匹配/对配业务。
3. 遥控器对配完成后，再初始化 IMU 和磁力计。
4. 油门应尽早保持实时可控。
5. 只有 IMU 和磁力计初始化完成、航向状态有效后，才允许自稳和巡航。

设计意图：

- 上电后先保证遥控器能尽快接管。
- 手动油门控制不应依赖 IMU、磁力计或航向 ready 状态。
- 自稳、定向巡航等依赖姿态/航向的功能，必须等待传感器状态有效后再开放。

约束：

- 磁力计 IIC 不做非阻塞化。
- QMC6309 初始化和读取保持阻塞式。
- 原因是当前 IIC 总线存在卡住风险，非阻塞状态机会增加系统复杂度和不确定性。

## 3. 磁力计校准问题

当前工程中已有 QMC6309 磁力计读取和航向融合逻辑，但主要依赖固定安装偏角和运行时滤波，没有完整的硬铁/软铁校准流程。

后续应新增一个独立的磁力计校准扩展模块，支持：

- 遥控器触发校准流程。
- 状态机式校准，便于未来扩展。
- 采集磁力计三轴数据。
- 计算硬铁偏移。
- 计算简单软铁比例修正。
- 将校准参数保存到 EEPROM。
- 开机自动读取 EEPROM 中的校准参数。
- EEPROM 参数无效时使用默认参数。

## 4. 第一版快速水平罗盘校准方案

第一版不做 PX4 飞控那种完整六面行业级校准。黑珍珠是水面船，主要依赖水平航向，用户需要的是简单、快速、有效、容易理解的校准动作。

产品名称建议使用：

```text
罗盘校准
```

不要在用户侧使用“硬铁校准”“软铁校准”“磁力计三轴椭球拟合”等复杂说法。

### 4.1 用户真实动作

用户只需要执行一个动作：

```text
将船保持水平，缓慢原地旋转，直到提示校准完成。
```

面向用户的完整说明建议为：

```text
请将船放在岸上空旷位置，远离汽车、铁架、磁铁和大电流电源线。
进入罗盘校准后，电机不会输出。
请保持船体水平，缓慢旋转船体，直到提示校准完成。
```

注意事项：

- 不要求用户数几圈。
- 不要求用户记 20 秒、30 秒或 60 秒。
- 不要求用户翻转船体。
- 不要求用户做 8 字动作。
- 不要求用户理解 X/Y/Z 三轴。
- 用户只需要持续慢慢转，什么时候结束由系统判断。

### 4.2 代码内部控制逻辑

校准时长、采样数量和合格判定全部由代码负责。

建议第一版内部规则：

```text
预热时间：2 秒，丢弃刚进入校准时的不稳定数据。
最短采集时间：20 秒，20 秒前不允许完成。
自动完成窗口：20-45 秒，数据合格后自动保存并退出。
最长超时：60 秒，仍不合格则失败退出，不保存 EEPROM。
采样周期：50 ms 或 100 ms   （根据磁力计自己的采样周期来  可以配置寄存器 让他高速刷新）。
```

用户界面和遥控器侧不暴露这些时间参数，只提示“正在校准，请缓慢旋转”。

### 4.3 第一版校准范围

第一版只追求水面航向够用，不追求飞控级三轴精度。

建议第一版只强制校准：

- X/Y 平面硬铁 offset。
- X/Y 平面简单 scale。

Z 轴可以采集并记录 min/max，但不作为第一版保存成功的强制条件。后续如果要做完整姿态级磁力计融合，再扩展为完整三轴校准。

基础计算方式：

```text
offset_x = (max_x + min_x) / 2
offset_y = (max_y + min_y) / 2

radius_x = (max_x - min_x) / 2
radius_y = (max_y - min_y) / 2

avg_radius = (radius_x + radius_y) / 2

scale_x = avg_radius / radius_x
scale_y = avg_radius / radius_y
```

航向计算前应用：

```text
cal_x = (raw_x - offset_x) * scale_x
cal_y = (raw_y - offset_y) * scale_y
```

### 4.4 防误操作和失败判定

校准不能只靠用户动作，必须有足够的防呆代码。

保存前至少检查：

- 样本数量足够。
- X 轴 span 足够。
- Y 轴 span 足够。
- X/Y span 比例不能离谱。
- offset 不能离谱。
- scale 不能离谱。
- IIC 读取失败次数不能超过限制。
- 用户不能完全没转船。

典型失败场景：

- 用户没有转船，X/Y span 太小，失败，不保存。
- 用户只小范围晃动，覆盖不够，失败，不保存。
- 用户转得太快或乱甩，异常点过多，丢弃异常点或失败。
- 附近有大铁块或强磁干扰，offset/scale 离谱，失败。
- QMC6309 读取失败或 IIC 异常次数过多，失败。
- 超过最长时间仍不合格，失败。
- 用户取消校准，退出，不覆盖旧参数。

失败时必须保留 EEPROM 里的旧有效参数，不能用坏数据覆盖。

### 4.5 成功与保存策略

校准成功条件由代码自动判断。达到条件后自动完成并保存 EEPROM，不要求用户再按“保存”。

成功后行为：

- 将新参数写入 EEPROM。
- RAM 中立即使用新参数。
- 记录采样数量、X/Y min/max、offset、scale 和校准结果日志。
- 退出校准状态，恢复正常控制逻辑。

如果 EEPROM 写入失败：

- 不应破坏旧参数。
- 可以在 RAM 中临时使用新参数。
- 日志中标记“校准成功但保存失败”，重启后不保证保留。

### 4.6 MCU 计算约束

当前 MCU 没有 FPU，磁力计校准和运行时修正不能引入大量浮点数计算，避免卡住主循环或影响油门实时性。

实现约束：

- 校准参数使用定点数保存，scale 建议使用 Q10 格式，`1024` 表示 `1.0`。
- offset 使用整数原始计数值保存。
- 运行时修正必须使用整数计算，不在高频路径中使用 `float`/`double`。
- 不做复杂椭球拟合、矩阵求逆、最小二乘等重计算算法。
- 除法尽量只放在校准完成时计算参数，不放在每次磁力计读取的高频路径。
- 运行时应用校准时使用 `int32` 做中间值，避免乘法溢出。

运行时修正建议形式：

```c
cal_x = ((int32)(raw_x - offset_x) * scale_x_q10) >> 10;
cal_y = ((int32)(raw_y - offset_y) * scale_y_q10) >> 10;
```

EEPROM 中保存的 scale 也应保存为 Q10 定点值，避免重启加载后还需要浮点转换。

## 5. 校准状态机建议

建议磁力计校准模块采用独立状态机：

- `IDLE`：空闲。
- `LOAD`：加载 EEPROM 参数。
- `COLLECTING`：采集校准数据。
- `VALIDATE`：校验采集数据是否有效。
- `SAVE`：保存到 EEPROM。
- `DONE`：校准完成。
- `FAILED`：校准失败。
- `CANCELLED`：校准取消。

## 6. 遥控器触发方式

当前不固定遥控器按键映射。

后续应将磁力计校准作为扩展模块插入，按键入口可以预留，但具体按键后面再决定。

可选方案：

- B：开始校准。
- C：完成并保存。
- D：取消校准。

当前先不写死，避免影响遥控器现有业务设计。

## 7. 校准期间电机策略

当前决策：岸上磁力计校准期间禁用电机输出。

原因：

- 磁力计校准需要用户手动旋转船体。
- 岸上校准时允许油门输出存在安全风险。
- 校准期间不应允许自稳和巡航。
- 完成或取消校准后，再恢复正常控制逻辑。

## 8. EEPROM 存储

用户提供的 EEPROM 区域：

```text
0xFE2800 - 0x01D800
```

后续应在该用户 EEPROM 区域内为磁力计校准参数分配独立地址。具体地址在实现前需要结合 STC 下载配置和现有 EEPROM 使用情况确认，避免覆盖其他配置。

建议保存内容：

- magic 标识。
- version 版本号。
- 数据长度。
- X/Y/Z 三轴 offset。
- X/Y/Z 三轴 scale。
- 采样数量。
- checksum 校验值。
- 返航点数据。

默认行为：

- EEPROM 数据有效：加载校准参数。
- EEPROM 数据无效：使用默认参数。
- 默认参数为 offset = 0，scale = 1.0。

## 9. 航向、自稳与巡航关系

磁力计校准只解决磁力计原始数据修正问题，不直接替代安装角修正。

需要区分：

- 硬铁/软铁校准：修正磁力计测量畸变。
- 安装偏角：修正磁力计安装方向与船头方向的夹角。
- 磁偏角：修正地理磁北与真北差异。
- 总偏角  安装和磁偏合二为一。

功能开放条件：

- 手动油门：不依赖 IMU/磁力计初始化完成。
- 自稳：必须等待 IMU 和磁力计初始化完成，并且航向 ready。
- 巡航：必须等待 IMU 和磁力计初始化完成，并且航向 ready。
- 校准期间：禁止自稳、巡航和电机输出。

## 10. 后续实现建议

建议新增独立模块：

```text
Code_boweny/Device/QMC6309/MagCalib.c
Code_boweny/Device/QMC6309/MagCalib.h
```

推荐接口：

```c
void MagCalib_Init(void);
void MagCalib_Load(void);
void MagCalib_RequestStart(void);
void MagCalib_RequestFinish(void);
void MagCalib_RequestCancel(void);
void MagCalib_Service(u32 now_ms);

u8 MagCalib_IsActive(void);
u8 MagCalib_IsValid(void);

u8 MagCalib_Apply(
    int16 raw_x,
    int16 raw_y,
    int16 raw_z,
    int16 *out_x,
    int16 *out_y,
    int16 *out_z
);
```

主循环中可周期调用：

```c
MagCalib_Service(now_ms);
```

磁力计航向计算前调用：

```c
MagCalib_Apply(...);
```

## 11. 验证场景

静态验证：

- EEPROM 数据结构打包/解包正确。
- checksum 错误时不加载参数。
- 默认参数不影响原有磁力计读取。
- 校准状态机状态切换正确。

岸上验证：

1. 上电。
2. 遥控器完成匹配。
3. 进入磁力计校准模式。
4. 电机输出被禁用。
5. 保持船体水平，持续缓慢旋转，直到系统自动提示完成。
6. 系统自动完成校准并保存 EEPROM。
7. 重启设备。
8. 确认 EEPROM 参数被正确加载。
9. 确认航向角稳定性优于校准前。

功能验证：

- 校准期间不能进入巡航。
- 校准期间不能进入自稳。
- 校准完成后，航向 ready 后才能进入自稳/巡航。
- 磁力计 IIC 仍保持阻塞式访问。
